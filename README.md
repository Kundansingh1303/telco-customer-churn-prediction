# Telco Customer Churn Prediction

## Project Overview
This project uses exploratory data analysis (EDA) and machine learning classification models to predict customer churn in the telecommunications industry.

## Objectives
- Analyze customer churn patterns.
- Clean and prepare the dataset.
- Train four classification models.
- Compare models using standard evaluation metrics.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Models
1. Logistic Regression
2. Decision Tree Classifier
3. Random Forest Classifier
4. K-Nearest Neighbors (KNN)

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
- Classification Report

## Dataset
Telco Customer Churn dataset.

Source: https://www.kaggle.com/datasets/blastchar/telco-customer-churn

## Results
Logistic Regression achieved 80.70% accuracy and an F1-score of 60.92% in the current experiment. These results are based on the notebook's evaluation.

## How to Run
1. Download or clone this repository.
2. Install the required Python libraries.
3. Download the dataset from Kaggle if needed.
4. Open `file_1.ipynb` in VS Code or Jupyter Notebook.
5. Run the notebook cells.
